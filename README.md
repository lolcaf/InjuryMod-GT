# Injury Mod
Ever bored of being immortal? With this mod you can get hurt from anything that should realistically harm you. Maybe think twice before jumping from a high place.
You can get hurt from lava, thermal volumes, drowning, smacking the ground too hard, high fall.\
If you find a bug please report it to the [Issues Tab](https://github.com/lolcaf/InjuryMod-GT/issues)
## Dependency
This mod depends on [Utilla](https://github.com/sirkingbinx/Utilla/releases/latest) (1.5.0+)
## How To Use
+ Install the mod with BepInEx
+ Join a modded lobby with Utilla
+ Have Fun!
## Secret
